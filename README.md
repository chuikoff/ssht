# SSHT — Terminal SSH Connections & Tunnel Manager

Терминальная утилита с полноэкранным TUI-интерфейсом для управления SSH-подключениями и фоновыми SSH-тоннелями (Local, Remote, Dynamic SOCKS5).

## ✨ Возможности

1. **Управление SSH соединениями**:
   - Автоматическое чтение существующих хостов из стандартного `~/.ssh/config`.
   - **Дата и время последнего подключения**: автоматическая фиксация каждого входа на сервер и отображение в человекочитаемом формате (*"Только что"*, *"15 мин. назад"*, *"Сегодня, 16:45"*, *"Вчера"*, *"2026-10-25"*).
   - **Проверка доступности (Ping) для всех хостов** в один клик (`[p]`) с параллельным замером задержки отклика (`● 28ms`, `✖ OFFLINE`).
   - **Переименование подключений и назначение псевдонимов (`[n]`)**: создание удобных коротких алиасов прямо в `~/.ssh/config` с автоматическим обновлением зависимых тоннелей.
   - Мгновенное подключение к выбранному серверу по нажатию `[Enter]` или двойному клику мыши (полноценная интерактивная сессия с бесшовным возвратом в TUI).
   - Добавление новых SSH-хостов прямо из интерфейса (`[a]`) с записью в `~/.ssh/config`.
   - Быстрое создание тоннеля для выбранного хоста (`[t]`).
   - Поиск и фильтрация по псевдониму (alias), IP-адресу или логину (`[/]`).

2. **Управление SSH тоннелями**:
   - **Local Forward (`-L`)**: проброс локального порта к удалённому сервису (например, доступ к Postgres базы данных на сервере через `localhost:5432`).
   - **Remote Forward (`-R`)**: проброс локального сервиса на удалённый сервер.
   - **Dynamic Forward (`-D`)**: создание локального SOCKS5-прокси через удалённый сервер.
   - **Быстрое открытие в браузере (`[o]`)**: мгновенное открытие `http://localhost:<порт>` в системном браузере по умолчанию для любого локального веб-сервиса (Grafana, pgAdmin, Kibana, Web UI) или SOCKS5-прокси.
   - **Авто-переподключение (Watchdog)**: фоновый сторожевой таймер отслеживает состояние тоннелей и автоматически восстанавливает соединение при разрывах сети или выходе системы из сна.
   - Включение и выключение тоннелей в один клик (`[Space]` или `[Enter]`).
   - Индикаторы статуса в реальном времени:
     - `● АКТИВЕН` (зеленый) — процесс запущен, локальный порт слушает входящие соединения.
     - `↻ ПЕРЕПОДКЛ...` (пурпурный) — автоматическое восстановление соединения.
     - `○ ВЫКЛЮЧЕН` (серый) — тоннель остановлен.
     - `◐ ЗАПУСК...` (желтый) — инициализация соединения.
     - `✖ ОШИБКА` (красный) — ошибка (с возможностью открыть логи `[l]`).
   - Проверка занятости портов (защита от конфликта портов с другими приложениями).
   - Остановка всех тоннелей в одно нажатие (`[s]`).
   - Автозапуск (AutoStart) при старте программы для нужных тоннелей.

3. **Фоновая работа и системная интеграция (CLI)**:
   - **Выход в фон (`[b]` / "В фон")**: закрытие TUI-интерфейса с сохранением всех работающих тоннелей в операционной системе.
   - **Headless-режим демона (`ssht daemon`)**: запуск в качестве фоновой службы без интерфейса с автоматическим подъемом тоннелей и сторожевым мониторингом.
   - **Управление из скриптов и терминала**:
     - `ssht start-all` — запустить все тоннели из консоли.
     - `ssht stop-all` — остановить все активные тоннели.
     - `ssht status` — компактная сводная таблица статусов тоннелей и их PID.

4. **Резервное копирование, экспорт и импорт настроек**:
   - Полный экспорт всех SSH-хостов, тоннелей и истории в единый переносимый JSON-файл (`[x]` или клик по кнопке `[Экспорт]`).
   - Импорт и восстановление настроек (`[i]` или клик по кнопке `[Импорт]`) с выбором режима:
     - **Объединить (Merge)**: добавление новых хостов и тоннелей с сохранением текущих.
     - **Заменить (Overwrite)**: полное восстановление из бэкапа.
   - Быстрый экспорт/импорт из командной строки без входа в TUI:
     - `ssht export [backup.json]`
     - `ssht import <backup.json>`

5. **CI/CD и GitHub Releases**:
   - Автоматическая сборка мультиплатформенных бинарников для Windows (amd64/arm64), Linux (amd64/arm64) и macOS (amd64/arm64) через GitHub Actions (`.github/workflows/release.yml`).
   - Автоматическая публикация релизов с контрольными суммами sha256.

## 🚀 Быстрый старт

### Запуск готового бинарника
В каталоге проекта уже собран `ssht.exe`:
```powershell
ssht
```

Либо запустите через `go run`:
```powershell
go run .
```

### Команды CLI
```powershell
# Запуск полноэкранного интерфейса
ssht

# Фоновый сторож (автозапуск и авто-переподключение)
ssht daemon

# Запуск / остановка всех тоннелей из консоли
ssht start-all
ssht stop-all

# Проверка статуса
ssht status

# Экспорт / импорт настроек
ssht export my_backup.json
ssht import my_backup.json
```

## 🖱️ Управление мышью (Mouse Support)

- **Клик по вкладкам вверху**: прямое переключение между `1. SSH Подключения`, `2. SSH Тоннели` и `3. Справка`.
- **Колесико мыши (Scroll Wheel)**: плавная прокрутка списков и логов вверх и вниз.
- **Одиночный клик по строке**: выбор нужного хоста или тоннеля.
- **Двойной клик по строке**:
  - В списке хостов: **мгновенное подключение по SSH**!
  - В списке тоннелей: **включение / выключение** (ON / OFF)!
- **Клик по кнопкам внизу**: нажатие на кнопки `[Подключиться]`, `[Браузер]`, `[Добавить]`, `[Изменить]`, `[Удалить]`, `[В фон]`, `[Выход]` и др.
- **Модальные окна**: клик по полям ввода активирует фокус на них, клик по `< LOCAL >` или `< Да >` переключает тип / автозапуск / автоповтор, клик по кнопкам сохраняет или закрывает окно.

## ⌨️ Горячие клавиши

### Глобальные
| Клавиша | Действие |
|---|---|
| `[Tab]` / `[Shift+Tab]` | Переключение между вкладками (*Подключения* / *Тоннели* / *Справка*) |
| `[1]`, `[2]`, `[3]` | Прямой переход на вкладку 1, 2 или 3 |
| `[↑]` / `[k]`, `[↓]` / `[j]` | Перемещение по списку вверх/вниз |
| `[Home]` / `[g]`, `[End]` / `[G]` | Переход в начало / конец списка |
| `[/]` | Поиск / фильтрация по текущему списку (для выхода: `Enter` или `Esc`) |
| `[b]` | **Выход в фон** (оставить все тоннели работать в фоне) |
| `[q]` или `[Ctrl+C]` | Выход из программы с корректной остановкой активных тоннелей |

### Вкладка 1: SSH Подключения
| Клавиша | Действие |
|---|---|
| `[Enter]` | **Подключиться** к выбранному хосту по SSH |
| `[p]` или `[c]` | **Проверить доступность для всех хостов** (замер задержки) |
| `[n]` | **Переименовать хост** (задать псевдоним / alias) |
| `[a]` | **Добавить хост** в `~/.ssh/config` |
| `[t]` | **Создать тоннель** для выбранного хоста |
| `[x]` | **Экспорт настроек** (бэкап в JSON) |
| `[i]` | **Импорт настроек** (восстановление из JSON) |
| `[b]` | Выход в фон (оставить процессы) |

### Вкладка 2: SSH Тоннели
| Клавиша | Действие |
|---|---|
| `[Space]` или `[Enter]` | **Включить / Выключить** тоннель (ON / OFF) |
| `[o]` | **Открыть в браузере** (`http://localhost:порт`) |
| `[a]` | **Добавить новый тоннель** (с опцией автоповтора) |
| `[e]` | **Редактировать** выбранный тоннель |
| `[d]` | **Удалить** тоннель |
| `[l]` | Посмотреть **логи / диагностику ошибки** тоннеля |
| `[s]` | **Остановить все** активные тоннели |
| `[b]` | Выход в фон (оставить тоннели активными) |
